FINDESIGN — сайт-визитка. Папка для загрузки на хостинг.
============================================================

ЧТО ВНУТРИ
------------------------------------------------------------
index.html            — сам сайт (одна страница, всё внутри)
en/index.html         — английская версия сайта по адресу /en/
images/               — фотографии, мокапы проектов, логотипы
favicon.svg           — иконка сайта (буква F), основная
favicon-16.png        — иконка 16×16 (старые браузеры)
favicon-32.png        — иконка 32×32
favicon-192.png       — иконка для Android
apple-touch-icon.png  — иконка для iPhone/iPad (на рабочий стол)
og-image.png          — картинка-превью при отправке ссылки в мессенджерах
site.webmanifest      — манифест (название/иконки для «на главный экран»)
robots.txt            — разрешение для поисковиков + ссылка на карту сайта
sitemap.xml           — карта сайта для поисковиков
404.html              — страница «страница не найдена»
.htaccess             — настройки сервера (сжатие, кэш, 404, HTTPS)


КАК ЗАГРУЗИТЬ НА ХОСТИНГ
------------------------------------------------------------
1. Зайдите в панель хостинга (или подключитесь по FTP, напр. через FileZilla).
2. Откройте корневую папку сайта. Обычно она называется:
      public_html   (reg.ru, beget, большинство хостеров)
   или www / htdocs / httpdocs.
3. Загрузите туда ВСЁ СОДЕРЖИМОЕ этой папки (вместе с папкой images
   и файлом .htaccess). Не саму папку deploy, а то, что внутри неё.
4. Откройте сайт в браузере — он должен сразу работать.

ВАЖНО: файл .htaccess начинается с точки и в некоторых файловых
менеджерах скрыт. Включите показ скрытых файлов, чтобы его не потерять.

ЯНДЕКС.МЕТРИКА (счётчик посещений)
------------------------------------------------------------
1. Создайте счётчик на https://metrika.yandex.ru — получите номер
   (например, 99887766).
2. В index.html найдите строку:
       var YM_ID="XXXXXXXX";
3. Замените XXXXXXXX на номер своего счётчика и сохраните.
   Пока стоит XXXXXXXX — счётчик не подключается (это нормально).


SSL / HTTPS
------------------------------------------------------------
Подключите бесплатный SSL-сертификат в панели хостинга (обычно
кнопка «Let's Encrypt»). После этого, чтобы сайт всегда открывался
по https, откройте .htaccess и раскомментируйте блок «Переадресация
на HTTPS» (уберите # в начале строк).
